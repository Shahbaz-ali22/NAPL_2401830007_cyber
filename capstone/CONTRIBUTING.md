# Capstone Contribution Notes

This folder contains documentation for ENSP465 Capstone Phase I: Smart Expense Tracker Using Go.

## Working on this project
1. Keep Phase I documentation focused on requirements, the proposed solution, design, scope, and planning.
2. Clearly distinguish planned features from features actually implemented and tested.
3. Use descriptive commit messages.
4. Do not commit local databases, passwords, API keys, or other private information.
5. Update the README and design diagrams whenever the approved project design changes.
